# ugm2.github.io

Unai Garay Maestre's personal website — [ugm2.github.io](https://ugm2.github.io/).

A three-ink risograph print: fluorescent pink, yellow and hunter green on warm
cream. The portrait is re-printed live in WebGL and follows the cursor, and the
career section is a small printed 3D road with one landmark per company.

Static HTML, CSS and vanilla JS. No build step and no framework. GitHub Pages
serves it straight from `main` at the repository root.

## Preview locally

```
python3 -m http.server 8000
```

Then open <http://localhost:8000>. It has to be served over HTTP (ES modules and
WebGL textures don't load from `file://`), and it needs internet access for
Google Fonts and three.js.

## Layout

```
index.html              the whole page
404.html                not-found page (absolute asset paths, served at any depth)
robots.txt, sitemap.xml
.nojekyll               skip the Pages Jekyll step; nothing here needs Liquid
assets/css/site.css     tokens, riso print treatments, layout, mobile
assets/js/main.js       sound, nav + scroll-spy, stickers, road journey, previews
assets/js/print.js      the portrait's three-plate riso shader (raw WebGL2)
assets/js/road.js       the printed 3D road, car and landmarks (three.js, lazy)
assets/css/images/      project tiles (*.webp served), og-card.jpg
images/                 portrait master + its webp derivatives, favicon
tools/optimize-images.mjs
```

three.js (`three@0.186.1`) is loaded from jsDelivr through the import map in
`index.html`, only when the road section comes near the viewport. With reduced
motion, no WebGL or no JS, the road falls back to plain experience rows.

## Images

The `.png`/`.jpg` files are masters and are **not** loaded by the page. Every
image the browser fetches is a `.webp` derivative generated by:

```
npm install --no-save sharp && node tools/optimize-images.mjs
```

## Social card

`assets/css/images/og-card.jpg` (1200x630) is the Open Graph / Twitter card. It
is a static image rendered from the live portrait print; regenerate it by hand if
the headline changes.
