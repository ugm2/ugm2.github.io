# ugm2.github.io

Unai Garay Maestre's personal website — [ugm2.github.io](https://ugm2.github.io/).

Static HTML, CSS and vanilla JS. No build step, no framework, no dependencies
at runtime. GitHub Pages serves it straight from `main` at the repository root.

## Preview locally

```
python3 -m http.server 8000
```

Then open <http://localhost:8000>. Any static file server works; there is
nothing to compile.

## Layout

```
index.html              the whole page
404.html                not-found page (absolute asset paths, served at any depth)
robots.txt, sitemap.xml
.nojekyll               skip the Pages Jekyll step; nothing here needs Liquid
assets/css/
  main.css              tokens, reset, typography, primitives, section rhythm
  vibrant.css           backdrop, custom cursor, scroll reveals, hero, nav
  icons.css             @font-face + glyph map for the subset icon fonts
  skills.css  timeline.css  portfolio.css  research-patents.css  footer.css
assets/js/
  main.js               reveals, hero canvas, sticky nav, pointer treatments
  projects.js           project dialogs + carousels
assets/fonts/           Font Awesome subsets — see assets/fonts/README.md
assets/css/images/      project screenshots: *.png/*.PNG masters, *.webp served
images/                 portrait master + its webp derivatives, favicon
tools/optimize-images.mjs
```

## Images

The `.png`/`.jpg` files are masters and are **not** loaded by the page. Every
image the browser fetches is a `.webp` derivative generated by:

```
npm install --no-save sharp && node tools/optimize-images.mjs
```

Add a new screenshot to the master directory, add it to the list in that
script, rerun, and reference the `.webp`.

## Social card

`assets/css/images/og-card.jpg` (1200x630) is the Open Graph / Twitter card.
It is a static image; regenerate it by hand if the headline facts change.

## Formatting

```
npx --yes prettier@3 --write index.html 404.html "assets/css/*.css" "assets/js/*.js"
```
